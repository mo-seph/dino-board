MosasauraboardSimulator

Write a behaviour with an AI

Describe what you want the dinosaur to do. This page adds everything an AI model needs to know about the board, ready to paste into any AI chat.

  1. Write your idea: what you do to it, what it does back, and what it's for.
  3. Paste it into an AI chat (Claude, ChatGPT, Gemini or another) and send it.
  4. Copy the code it gives back, open the simulator, pick a light, paste the code over what is there and press Run it.
  5. If it stops with an error, press Copy the error in the simulator and paste that back to the AI.

What gets copied

Nothing is sent anywhere by this page: it only puts text on your clipboard.
